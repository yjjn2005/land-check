# 토지·건축 조회 (land-check)

주소 또는 PNU 입력 → 토지대장(지목·면적) · 토지이용계획(국토계획법 + 다른 법령 지역·지구) · 개별공시지가(연도별) · 토지특성(도로접면 등) · 건폐율/용적률 법정 상한과 대지면적 적용 최대 규모 · 용도별 건축물 · 행위제한 조회.

- 앱: https://yjjn2005.github.io/land-check/
- 프록시: https://land-check-api.yjjn2005.workers.dev (국토교통부 토지이용규제정보서비스 + 브이월드 국가중점 API 폴백)
- 데이터: 브이월드 오픈API(검색·국가중점), 국토교통부 토지이용규제정보서비스(공공데이터포털)
